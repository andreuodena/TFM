# TFM reproducible R analyses

This directory contains the R code used to generate the processed data and
statistical results presented in the TFM figures. It also contains a pdf file containing the supplementary figure 1.

## First analysis: bulk RNA-seq preprocessing

`01_bulk_RNAseq_preprocessing.Rmd` performs the following steps:

1. loads the raw count matrix and metadata;
2. reports library sizes and batch/subtype composition;
3. retains genes with more than 10 reads in at least 15 PDX models;
4. performs TMM normalisation and calculates log2-CPM expression;
5. performs an unsupervised PCA; and
6. saves the three supplementary plots in SVG format.

The only supplementary figures generated by this analysis are library size,
subtype composition by sequencing batch and PCA.

## Required local files

Create a `data` directory containing:

```text
data/260824_Counts.csv
data/260824_Metadata.csv
```

The files are semicolon-delimited. Raw molecular and clinical data are not
included in the public repository.

## Required packages

```r
install.packages(c("rmarkdown", "knitr", "ggplot2"))

if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}

BiocManager::install("edgeR")
```

## Run the analysis

Open R from the repository root and run:

```r
rmarkdown::render("01_bulk_RNAseq_preprocessing.Rmd")
```

Supplementary figures are written to `figures/supplementary_RNAseq_QC`.

## Second analysis: PAM50 intrinsic-subtype classification

`02_PAM50_classification.Rmd` performs the following steps:

1. repeats the filtering and TMM normalisation used in the preprocessing analysis;
2. maps gene symbols to Entrez identifiers;
3. calculates Parker original and `genefu.scale` PAM50 calls;
4. exports the model-level subtype calls and PAM50-gene expression matrix; and
5. generates a supplementary PCA annotated by Parker PAM50 subtype and batch.

Install the additional Bioconductor packages with:

```r
if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}

BiocManager::install(c(
  "BreastSubtypeR",
  "SummarizedExperiment",
  "S4Vectors"
))
```

Run the analysis from the repository root with:

```r
rmarkdown::render("02_PAM50_classification.Rmd")
```

PAM50 data are written to `results/PAM50`. The supplementary PCA is written
exclusively in SVG format to `figures/supplementary_PAM50`.

## Third analysis: genomic-transcriptomic concordance

`03_genomic_transcriptomic_concordance.Rmd` reproduces the direct CNV-to-gene
expression analyses used for Figure 3A, calculates Hallmark ssGSEA scores for
each PDX model and tests the estrogen-response, PI3K/AKT/mTOR and RB/cell-cycle
genomic associations used in Figure 3. The association models use HC3 robust
standard errors and adjust for Parker PAM50 intrinsic subtype. The script also
reproduces the strict PTEN-deletion analysis in which non-deletion PTEN events
are excluded.

The analysis generates 11 CSV files and no figures:

```text
results/genomic_transcriptomic_concordance/Direct_CNV_to_expression_associations_PAM50_adjusted_model_data.csv
results/genomic_transcriptomic_concordance/Direct_CNV_to_expression_associations_PAM50_adjusted_statistics.csv
results/genomic_transcriptomic_concordance/PDX_Hallmark_ssGSEA_scores.csv
results/genomic_transcriptomic_concordance/Composite_estrogen_pathway_alteration_PDX_status.csv
results/genomic_transcriptomic_concordance/Composite_estrogen_pathway_alteration_PAM50_adjusted_statistics.csv
results/genomic_transcriptomic_concordance/Estrogen_response_ESR1_pathway_alterations_PAM50_adjusted_statistics.csv
results/genomic_transcriptomic_concordance/PI3K_AKT_mTOR_alterations_PDX_status.csv
results/genomic_transcriptomic_concordance/PI3K_AKT_mTOR_alterations_PAM50_adjusted_statistics.csv
results/genomic_transcriptomic_concordance/PTEN_deletion_PI3K_mTORC1_PAM50_adjusted_statistics.csv
results/genomic_transcriptomic_concordance/RB_cell_cycle_dysregulation_PDX_status.csv
results/genomic_transcriptomic_concordance/RB_cell_cycle_dysregulation_PAM50_adjusted_statistics.csv
```

Install the additional packages with:

```r

```

Run the PAM50 classification first and then render this analysis:

```r
rmarkdown::render("02_PAM50_classification.Rmd")
rmarkdown::render("03_genomic_transcriptomic_concordance.Rmd")
```

## Fourth analysis: baseline Hallmark GSEA by treatment response

`04_drug_response_Hallmark_GSEA.Rmd` compares baseline expression between
sensitive and resistant models across ten treatment cohorts. For each cohort,
limma moderated t-statistics are calculated with adjustment for Parker PAM50
intrinsic subtype when estimable and used to rank genes for Hallmark GSEA with
`fgseaMultilevel`. Positive NES values indicate enrichment in sensitive models
and negative values indicate enrichment in resistant models.

The analysis generates four CSV files and no figures:

```text
results/drug_response_Hallmark_GSEA/Hallmark_GSEA_all_results.csv
results/drug_response_Hallmark_GSEA/Hallmark_GSEA_model_summary.csv
results/drug_response_Hallmark_GSEA/Hallmark_GSEA_input_annotations.csv
results/drug_response_Hallmark_GSEA/Hallmark_GSEA_global_FDR_significant.csv
```

Install the required packages with:

```r
install.packages("msigdbr")

if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}

BiocManager::install(c("edgeR", "limma", "fgsea"))
```

Run the PAM50 classification first and then render the GSEA analysis:

```r
rmarkdown::render("02_PAM50_classification.Rmd")
rmarkdown::render("04_drug_response_Hallmark_GSEA.Rmd")
```

## Fifth analysis: continuous and joint olaparib-cisplatin GSEA

`05_olaparib_cisplatin_GSEA.Rmd` performs PAM50-adjusted analyses of:

1. continuous olaparib benefit using Hallmark and Reactome gene sets;
2. continuous cisplatin benefit using Hallmark and Reactome gene sets;
3. three Reactome GSEA comparisons among dual-responsive,
   cisplatin-selective and dual-resistant models.

The four joint response groups are exported, including the two
olaparib-selective models. This small group is not included in pairwise GSEA.
The analysis generates CSV result, ranking, annotation and model-summary files
and does not generate figures.

Add the following semicolon-delimited file to the local `data` directory:

```text
data/260827_Metadata_PARPi_Cisplatin.csv
```

This file must contain model identifiers, quantitative best-response values and
categorical mRECIST responses for olaparib and cisplatin. Install the packages
listed for the fourth analysis, run PAM50 classification and then render the
notebook:

```r
rmarkdown::render("02_PAM50_classification.Rmd")
rmarkdown::render("05_olaparib_cisplatin_GSEA.Rmd")
```

Results are written to `results/olaparib_cisplatin_GSEA`.

## Sixth analysis: paired PARPi-sensitive and acquired-resistant PDXs

`06_paired_PARPi_acquired_resistance_GSEA.Rmd` compares paired
olaparib-treated and untreated samples separately in seven baseline
PARPi-sensitive PDXs and their seven acquired-resistant counterparts. Human
RNA-seq reads are retained, gene-level treatment effects are estimated using
paired limma models and moderated t-statistics are used for Hallmark and
Reactome GSEA. Positive NES values indicate higher expression after olaparib
treatment.

The analysis generates six CSV files and no figures:

```text
results/paired_PARPi_acquired_resistance_GSEA/Paired_treatment_sample_annotations.csv
results/paired_PARPi_acquired_resistance_GSEA/Paired_treatment_model_summary.csv
results/paired_PARPi_acquired_resistance_GSEA/Paired_treatment_DE_all_genes.csv
results/paired_PARPi_acquired_resistance_GSEA/Paired_treatment_GSEA_all_results.csv
results/paired_PARPi_acquired_resistance_GSEA/Paired_treatment_GSEA_within_collection_FDR_significant.csv
results/paired_PARPi_acquired_resistance_GSEA/Paired_treatment_GSEA_global_FDR_significant.csv
```

Add the paired count matrix and metadata to the local `data` directory, then
render the analysis:

```r
rmarkdown::render("06_paired_PARPi_acquired_resistance_GSEA.Rmd")
```
